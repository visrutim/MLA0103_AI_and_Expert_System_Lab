MLA01 - AI & Expert System Laboratory: Experiment Code Pack

Contains one Python (.py) file for each of the 27 experiments listed in the PDF.
Experiment 25 also includes a .pl file because the PDF explicitly specifies Prolog;
the matching Python implementation is included as 25_best_first_search_prolog.py.

How to run:
1. Install Python 3.
2. Open a terminal in this folder.
3. Run a Python experiment, for example: python 01_bfs.py

External packages:
- Experiments 1-11, 14-20, 22-24, 25 Python version, 26-27 use only the Python standard library.
- Experiments 12 and 13: pip install scikit-learn
- Experiment 21: pip install numpy scikit-learn
- For the original Prolog version of Experiment 25, install SWI-Prolog and use the query in the .pl file.

Notes:
- Small illustrative datasets and knowledge bases are used for easy demonstration.
- Decision-tree and neural-network examples are not for real loan decisions or medical diagnosis.
- Diet and medical expert systems are educational demonstrations, not professional advice.
