MLA01 - Artificial Intelligence and Expert Systems Laboratory
Python experiment collection based on the 27 experiments in the supplied PDF.

Run:
  python 01_breadth_first_search.py
Replace the filename with the experiment you want to run.

Optional dependency for Experiments 12 and 13:
  python -m pip install scikit-learn

Notes:
- Experiment 25 is specified as Prolog in the source PDF. This collection includes a clearly labelled Python equivalent to keep all files in .py format.
- The medical and diet examples are educational demonstrations, not medical advice.
- Experiment 20 uses fictional sample records only.
